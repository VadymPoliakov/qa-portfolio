# Приклад оформлення баг-репорта

**Назва бага (Summary):** Кнопка "Submit" залишається неактивною після заповнення всіх обов'язкових полів у формі реєстрації.

**Окруження (Environment):**
* Пристрій: PC (Windows 11)
* Браузер: Google Chrome (vers. 120.0)

**Кроки для відтворення (Steps to Reproduce):**
1. Відкрити головну сторінку сайту.
2. Перейти до розділу реєстрації (Sign Up).
3. Заповнити всі обов'язкові поля валідними даними (Email, Пароль).
4. Перевірити стан кнопки "Submit".

**Очікуваний результат (Expected Result):**
Кнопка "Submit" стає активною одразу після заповнення всіх обов'язкових полів, користувач може натиснути її для завершення реєстрації.

**Фактичний результат (Actual Result):**
Кнопка "Submit" залишається неактивною (сірою), навіть коли всі обов'язкові поля заповнені.
